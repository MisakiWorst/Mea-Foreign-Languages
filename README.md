## 🌸 碎碎念 | つぶやき

**Ciallo～(∠・ω< )⌒★**

这里是 **mea** (`MisakiWorst`) 的个人外语学习知识库，基于 **Obsidian** 构建并通过 Git 进行多端同步与版本管理。

除了日常的工程开发与折腾 Linux 之外，语言学习也是探索不同文化与思维方式的重要拼图。与其把笔记零散地堆在本地，不如以结构化的方式沉淀下来，方便随时检索、复盘与横向对比。

- 📖 **笔记工具**：Obsidian（配合双链、标签与定制化词表模板）
- 🎯 **当前主线**：日语向 **JLPT N1** 进阶，英语冲刺 **TOEFL** 高分
- 🧩 **学习方法**：注重词源拆解、语境例句积累，以及跨语种（日 / 英 / 德 / 西 / 希）的语法与词汇结构对照

<br/>

## 🗂️ 仓库结构 | Directory

```Mealab
Mea Foreign Languages/
├── 000.Mea Foreign Languages/   # 笔记总览、学习路线与索引看板
├── 001.词类与活用/              # 品词分类、动词/形容词/形容动词活用变形规则
├── 002.助词/                    # 格助词、副助词、接续助词、终助词核心用法与辨析
├── 003.助动词/                  # 使役、被动、可能、推量、否定、过去等助动词接续与语态
├── 004.指示词/                  # コソアド（こそあど）指示代词与现场/文脉指示体系
├── 005.疑问词/                  # 疑问词基本用法及「疑问词 + か / も / でも」泛指转化
├── 006.形式名词/                # こと、もの、の、わけ、はず、つもり等抽象名词语法化
├── 007.接尾词/                  # 词性转换、程度、状态与情感色彩接尾词归纳
├── 008.补助动词/                # ～ている、～てある、～ておく、～てしまう等体貌表达
├── 009.功能词/                  # 复合助词、接续表达与书面/口语功能词整理
├── 010.功能用语·句型/           # JLPT 核心文型分类、近义句型辨析与长难句拆解
├── 011.待遇表现/                # 尊敬语、自谦语、丁宁语及授受动词（やる・あげる・もらう・くれる）
└── README.md                    # 知识库说明文档
```

本仓库为纯 Markdown 知识库，支持本地 Obsidian 直接打开：

```Bash

git clone [https://github.com/MisakiWorst/N5.git](https://github.com/MisakiWorst/N5.git)

# 日常一键同步笔记
git add . && git commit -m "update notes" && git push
```
